## English

<a href="#top"><b>[↑ Back to top]</b></a>

I'm a Unity developer and game designer who cares about clean architecture (DI, event-driven code) as much as about how a mechanic actually *feels*. I'm happiest owning a feature end to end — designing the mechanic, architecting it, networking it for co-op, and polishing the UI around it. I also work comfortably on the web and in UI/UX when a project needs it.

> **What I bring:** someone who can take a gameplay idea all the way — design → architecture → multiplayer → UI — without it falling apart along the way.

### What I do

| Area | |
|---|---|
| **Gameplay & systems** | Combat, roguelike runs and autobattler logic in Unity 6 / C#, built on DI (VContainer) and an EventBus architecture |
| **Multiplayer & netcode** | Host-authoritative co-op with Netcode for GameObjects and Photon Fusion |
| **Game design** | Systems & combat design, balancing, jam-winning concepts — Game Designer on a shipped Steam title |
| **Tools, UI & UX** | In-engine UI (uGUI / TextMeshPro), reusable UI kits, Figma — at home across the design→implementation gap |
| **Web (secondary)** | React / Next.js / TypeScript — production sites with headless CMS, from design to deploy |
